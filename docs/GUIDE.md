## 一、开局原则（两份攻略共识）

1. **农场选标准农场**——可耕种区域最大、地形简单。本存档即标准农场 ✓
2. **不用把树和杂草清光**——清出可种田和行走的空间即可。树要留：橡树液做小桶酿酒（暴利）、枫糖浆做蜂箱+送礼；橡实/松果/枫树种子可合成田园小食（前期补品）。**AI 行动**：只清农田周边，留树。
3. **四季 28 天，过季作物全部枯死**——务必看种子说明。防风草 4 天熟。
4. **每天先看电视**：天气预报（明天下雨→不用浇水、可升级水壶）+运气占卜（幸运→钓鱼宝箱/矿梯；霉运→钓垃圾但能练级）+周日酱料女皇学菜谱。**AI 不能做**：看电视是菜单交互+选项，Remix 有 /menu/click 理论可点但未验证，跳过影响不大。
5. **蚯蚓冒头用锄头挖**：黏土/矿物/古物（捐图书馆）。**AI 能做**：surroundings 可见后 useOn。
6. **杂货店门口看日历和任务公告栏**。**AI 难**：读 UI 文本需截图+识图，可行但慢。

## 三、candor 攻略的核心细节（图版攻略没有的）

1. **开局杂货店采购**：花椰菜×2-3 包、豌豆×2-3 包（社区中心指定+任务常要），余钱买防风草和土豆。初级肥料施肥种金星花椰菜。
2. **黄水仙别乱送**：送皮埃尔/格斯涨好感（两人回寄钱和食谱）；留 3 朵——1 朵社区中心觅食包、1 朵居民任务备用、1 朵海莉生日。**皮埃尔生日春 26，送黄水仙暴增 2 心**。
3. **社区中心春季觅食包**：黄水仙、韭葱、野山葵、蒲公英各留一株，开放后立刻交。
4. **D13 彩蛋节买草莓**：至少 40 包。首收后钱升背包（12→24 格 2000g，**优先级最高**）。草莓留一部分腌渍（罐头箱：作物价值×2+50，两三天一罐）；罐头箱做 3-4 个就好（耗煤，不如蜂箱）。
5. **缺煤去矿坑 45-55 层乘电梯刷煤炭怪**。
6. **工具升级顺序：喷壶(一次到铜即可)→十字镐→斧头**。雨天升级不亏工时。
7. **钓鱼练习**：湖泊鱼平缓适合练级；钓鱼 2 级买鱼饵、6 级买最好钓竿+鱼钩；农场下方秘密森林池塘的鲤鱼几乎不动（但要钢斧开路）；威利的鳟鱼汤临时+钓级。**鱼缸收集包的鱼留一条解任务**。
8. **霉运钓鱼钓垃圾也涨经验**，垃圾乔家可乐送山姆刷好感。
