# 大肥鱼农场建设·总目标与规划（Master Plan）

> 生成: 2026-10-30 | 战略依据: 用户拍板"科技是第一生产力，先点科技造工具再扩大丰富农场，赚钱只为这一目标服务"
> 现状锚点: 秋25 · 2,982g · 农田90格(69蔓越莓+9南瓜+杂) · 竹竿钓鱼 · 矿洞未刷 · 铜壶未升 · loop自动化v3在跑

## 〇、总目标（一句话）

**一年内把农场建成"科技全自动"形态：铱壶/洒水器矩阵覆盖免人工浇水、温室开工、动物线起步、矿洞矿车直达——农场规模服务于这条科技线，不为扩而扩。**

## 一、三大里程碑（按季度）

| 里程碑 | 截止 | 验收标准（可量化） |
|---|---|---|
| **M1 水自由** | 冬10 | 铜水壶在手 + ≥10个普通洒水器铺满主田 → 浇水体力≈0，全田90格系统浇 |
| **M2 钱自由** | 春25(次年) | 腌菜罐≥6在转 + 鸡舍+3鸡日产蛋 + 温室已开(pantry全包交齐) → 日均被动收入≥500g |
| **M3 科技自由** | 夏末(次年) | 钢水壶+矿车解锁(Boiler Room全包) + 畜棚+2牛(山羊奶酪线) + 稳定下矿80层+ |

### Phase C 春1-夏1（动物线+温室印钞）
- C1 春1-12: 土豆为主力+花椰菜留1个给乔迪任务；**春13蛋节带≥1,500g买草莓**

### Phase D 夏1-夏末（M3验收）
- D1 金锭×5+10,000g → 金水壶(9格)；攒电池组(雷雨避雷针提前铺)

- D3 矿车+钢镐 → 稳定80-120层刷金矿；铱壶25,000g列为次年底目标
- D4 农田可扩(洒水器矩阵铺到哪扩到哪)——**至此才解锁"扩大农场"**

## 三、规模红线（用户拍板沿用）

- 农田冻结90格直到M1达成（浇水体力是硬瓶颈，田多=多烂地）
- 格数×2 ≤ 270-钓鱼预算120 → 当前体力下上限≈75格实耕+15格缓冲
- 只卖 鱼+农作物+垃圾（白名单），其余存箱
- 不买25,000g级大件之前不碰豪华装饰类消费

## 四、每日节奏模板（M1达成后生效）

```
6:00 起 → 洒水器自动(0体力) → 收获/补种
上午 → 矿洞日(周二/四) 或 钓鱼
下午 → 熔炉烧锭/腌菜罐补货/交收集包
傍晚 → 生日NPC送礼/采集物
23:00或体力<15 → 睡觉存档(铁律①)
```
