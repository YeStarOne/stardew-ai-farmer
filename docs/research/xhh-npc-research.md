# NPC社交研究（大肥鱼·小黑盒向）

> 来源: stardewvalleywiki.com (Friendship/Calendar页), 2026-10-29抓取。
> 目标: 用**我们已拥有/低成本可得的礼物**刷好感, 挂进day-loop每天自动送。

## 一、送礼规则(硬约束)

- 每人**每周最多2件**礼物, 每天每村1件上限不限村; **生日礼物好感×8**, 生日必送。
- 好感: 生日最爱+640 / 平日最爱+80 / 喜欢+45 / 普通+20; 每周不送-10。
- 好感100点=1心; 250心后好感每日-1(掉血), 全员+分项除外。

## 二、万能礼物(最省事, 全员"喜欢")

- **所有水果/蔬菜/工匠产品**(酒/奶酪/蛋黄酱/蜂蜜)→ 喜欢+45。我们的蔓越莓/南瓜随便送。
- 万能爱(全员最爱): 钻石、黄金浓缩咖啡、兔脚、珍珠、魔法糖冻。
- 全员讨厌: 所有鱼、所有宝石(除翡翠? 异性均讨厌野菜根) — **鱼和矿石别当礼物**。
- 例外: Pierre讨厌鱼/宝石, Clint喜欢所有宝石(!), Willy喜欢鱼。

## 六、day-loop挂接方案(待实现)

1. loop每早检查`BIRTHDAYS`表(硬编码上表)→ 当天生日的NPC, 从`GIFT_PLAN[name]`取礼物。
2. 礼物不存在包里→跳过(不专门花钱买, 除Robin spaghetti这种便宜的最爱)。
3. 送礼走`socialize.mjs`的`gift(target,item)`(warp到NPC/找NPC+`/gift`)。
4. 送完写日志, 同周同名跳过(每人每周2件上限, 别浪费名额)。
