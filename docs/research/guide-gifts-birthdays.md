# 送礼与生日全表（大肥鱼·AI执行版）

> 2026-10-30 | 来源: stardewvalleywiki.com 各村民页逐一实抓(Calendar+Pierre+Lewis+Robin+Clint+Willy+Pam+Evelyn已核)
> **为什么送礼**: 好感解锁配方/邮件回礼/减价/剧情/花舞配对; 目标**4心**够用, 不追满心。

## 一、机制铁律

1. **每周2刀/人**: 每人每周只收**2份**礼物, 每天最多送1份 → 名额稀缺别乱花。
2. **生日8倍**: 生日当天送最爱=640点(2.5心), 平时只80点 → **最爱留给生日, 平时送liked攒脸熟**。
3. **好感衰减**: 每天-10点(不交谈也扣), 交谈+20/天 → 每天见谁跟谁说话, 零成本。
4. 档位: 1心=250 / 2心=500 / 4心=1000 / 6心=1500。
5. 剧情好感事件达到心数次日触发, 别错过(尤其2心/4心)。
6. 生日额外+1名额: 每人每周2份**之外**生日当天还能再送1份(官方确认)。

## 二、通用礼物档位

- **万能最爱(全员最爱)**: 魔法岩糖、黄金南瓜、珍珠、五彩碎片、兔子脚。
  - ⭐珍珠=夜市美人鱼游戏每年1颗 → 留给冬18秘密圣诞或关键生日。
  - 黄金南瓜=灵异夜迷宫(奇数年)。
- **万能liked**: 黄金品质物品、所有工匠品(果酱/腌菜/蜂蜜酒)。
- **全员恨**: 鱼饵、黏土、杂志残页、鱼饲料 → 钓上来的垃圾绝不能送!
- 冬青(Holly)是**几乎所有人**(罗宾/刘易斯/克林特/潘姆/艾芙琳)的恨物, 冬天采集别手滑送出去。

## 六、AI执行纪律(day-loop挂接)

1. **每天先看日历**: 今天谁生日→有最爱就送(8倍+额外名额), 没有就只交谈(+20)。
2. **囤货节奏**(提前一季备):
   - 春18潘姆: 防风草(春种自产, 无需囤)
   - 夏24威利: 南瓜(头年秋存)或鲶鱼(雨天钓)
   - 秋21罗宾: 意大利面(酒吧220g)或桃子树
   - 冬20艾芙琳: 郁金香种(春天买)或巧克力蛋糕材料
   - 冬26克林特: 金锭/铱锭(矿线副产品)
3. **优先级**: 罗宾(建筑/升级) > 克林特(工具/冶炼·送锭就行) > 潘姆(巴士→沙漠) > 威利(钓具) > 皮埃尔 > 其他。
4. **别送错**: 冬青全员恨; 石英克林特恨(但艾比盖尔爱!)——同一块石头看人; 生鱼只送威利/李纳斯/塞巴斯蒂安/潘姆(neutral)。
5. **回礼红利**: 好感>0后刘易斯偶尔寄500g、罗宾/艾芙琳/克林特/潘姆寄礼物邮件, 顺带白赚。
