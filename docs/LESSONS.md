# 踩坑笔记 · AI 玩星露谷的坑位大全

这份文档记录了一个 AI Agent 自主玩《星露谷物语》过程中踩过的真实坑。每条都来自实际运行事故，附现象、根因、修法。

## 1. 锄地假成功（最坑）

**现象**：`expandField` 连续三天日志"翻地 8/10 成功"，但空耕地永远是 0，种子种不下去。

**根因**：直接调 `/use` 挥锄返回 `ok:true`，但工具动画没走完，格子上没有落判定——**返回值只代表"挥了动作"**。

**修法**：锄地一律走「行为学」mod 框选：

```js
await sel('Hoe');
const r = await behaviorSelect(x1, y1, x2, y2, 'left');  // left=工具模式
await behaviorWaitDone(5 * 60 * 1000);
```

实测 3×2 试锄 6/6、整条带 58 格一次锄完。已固化进 `lib.expandField`。

**铁律**：任何工具动作后必须回查 `/surroundings` 验证地形/状态真的变了。

## 2. 存档级冻结

**现象**：玩家 `canMove:false`，游戏时钟停走，重读存档依然冻结（自愈锁）。

**排查**：二分法移除所有 mod → 仍然冻结 → 与 mod 无关，是存档里的状态。

**修法**：强制 `/sleep` 重置状态 > 重启游戏 > 载档后睡觉。优先级从高到低。

## 3. 深夜时间烧穿

**现象**：手动杀掉 day-loop 排查问题，半小时后游戏时间烧到凌晨 00:40，第二天被跳过并收到昏倒罚金。

**根因**：night-guard 也停了，没人管睡觉，游戏时间按真实时间流逝。

**修法**：任何时刻接管角色前先看时间，>24:00 先 `/sleep`；night-guard 常驻兜底。

## 4. 半径静默跳过（排查头号嫌疑人）

**现象**：`replantAll` 日志显示"翻地成功"却"种 0 株"，无任何报错。

**根因**：播种检查用 `surr(8)`、补种用 `surr(14)`，超出半径的格子被 `if (!t) continue` 无声跳过。

**修法**：半径不够就放大；所有"静默跳过"类 bug 优先怀疑半径。

## 5. 浇水只浇干土 + 按行扫

- `watered=true` 的状态保持到次日清晨，重浇是纯浪费（用户观察）。
- 浇水是"走一格浇一格"串行：孤格要为它单独跑一趟，停十几秒；满排一路扫过去快数倍。
- **种植铁律：尽量保持一横排种满**；`waterAll` 已按行蛇形排序。

## 6. 体力预算

浇 ~93 格耗 ~170 体力（基础水壶 2/格），270 上限浇完田就没体力钓鱼了。

**铁律**：田规模 ≤ ~90 格；买种子前先算 格数×2 ≤ 270 − 钓鱼预算 120；洒水器（1 铜锭+1 铁锭，每早自动浇 4 格）是正解。

## 7. 背包满时的合成陷阱

`/craft Chest` 在背包满时会直接掉地上，`/drop` 是按单位不是按格子。合成前必须检查槽位（`lib.craftChest` 已加 ≥12 槽拒绝）。

## 8. 任务物品绝对保留

乔迪的花椰菜任务：`QUEST_RESERVE` 必须是**绝对保留**（该物品永不卖），不能按数量算——否则背包里多出的花椰菜会整叠卖进箱子。

## 9. 交互位置与朝向

- `/use` 只认面朝格；`warp` 到室内必须用 `/warp_into`。
- 商店购买 `/buy` 的 `count` 参数会被忽略，一次只买 1 个，需要循环。
- 种子 ID 表（实测）：防风草 472 / 大黄 478 / 甜瓜 479 / 番茄 480 / 蓝莓 481 / 辣椒 482 / 小麦 483 / 萝卜 484 / 红椰菜 485 / 杨桃 486 / 玉米 487 / 茄子 488 / 南瓜 490 / 蔓越莓 493 / 草莓 745 / 咖啡豆 433。

## 10. 菜单与对话框

- 普通对话推进用 `/key confirm`；**选项对话必须截图后 `/menu/click` 点选项**（`menu_close` 会取消选择）。
- 升级菜单（LevelUpMenu）的 OK 按钮位置会变，每次从 `/menu` 响应里取 `okButton` 坐标。
